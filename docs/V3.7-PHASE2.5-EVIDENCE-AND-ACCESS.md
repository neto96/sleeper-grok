## Waiver comparison summary

Global ROS top-choice/top-3/top-5 comparisons are blocked in all 12 rosters: 576 of 580 candidates lack retained usable evidence. The comparison concerns ONLY the common 4-player research subset; it does not identify the best free agent across the league. All three monotonic curves give the same subset order; that is ordinal agreement, not three independent validations.
Projected comparisons call the unchanged production waiver valuation using the captured Week 10 data and explicit frozen clock. For full rosters, the study selects one hypothetical drop by lowest captured legacy replacement consequence, then player ID. This is a controlled assumption, NOT a drop recommendation. No overflow or unresolved drop is valued. Unknown projection rows block a global projected winner. Tied best projected gains count as agreement if the ROS leader belongs to the tied winner set; top-k overlap is withheld when the kth boundary is tied.

Among supported subset projection comparisons, **0** have an untied ROS/immediate-top disagreement, **5** include the ROS leader among projected winners, and **7** are blocked. The subset ROS leader has a captured Week 10 bye; its ROS rank is not reduced. A bye does not by itself prove another add improves a given roster, especially when gains tie or a drop erases an upgrade.

## Access evidence and unresolved questions

Audit checked 2026-11-10 (America/Chicago). Official public documentation was read; no key was requested, subscription purchased, authenticated endpoint tested or provider data fetched. This is an engineering assessment, not a legal determination.
The [current API product page](https://www.fantasypros.com/api-data/) documents x-api-key authentication, free non-production prototyping, HOF personal/non-commercial production keys and a commercial offering with redistribution rights. It describes higher paid limits without numeric quotas. Technical existence is established; this account’s production entitlement and ROS response completeness are not.
The [access support article](https://support.fantasypros.com/hc/en-us/articles/49749297704475-How-do-I-request-access-to-the-FantasyPros-API) requires a paid, active HOF subscription for personal production access; a HOF trial is insufficient. It directs redistribution, organizational/revenue and high-volume use to a separate agreement. Personal use therefore matters, but does not establish permission for this hosted analyzer or a public UI.
The [linked API terms PDF](https://api.fantasypros.com/public/v2/terms-of-use) is dated October 27, 2020. It specifies confidential non-transferable keys, 1 request/second and 100/day, encourages caching, requires FantasyPros attribution, restricts competitive use and excludes historical player statistics/player-image URLs from that license. It allows certain continued personal use of previously retrieved data after termination subject to conditions. Those older limits and retention provisions cannot be assumed to govern a current paid key or MCP export. Exact ranking retention, cache TTL, deletion obligations, redistribution rights and applicability to this app require confirmation; no specific permitted TTL was established.
The [MCP connection guide](https://support.fantasypros.com/hc/en-us/articles/55212611981851-How-do-I-connect-to-the-FantasyPros-MCP-Server) documents account OAuth at api.fantasypros.com/mcp, without an API key, for supported AI clients. Free accounts can start; some advice tools require premium. It does not establish unattended web-app service access or permission to republish rankings. The ChatGPT authorization is not an app credential. A separately authorized client, session lifecycle and use-case permission would be needed; none was implemented or tested.
Manual private import and scheduled private storage remain conditional on the governing data license. A schedule cannot create rights absent from manual access. Proposed engineering policy, NOT provider terms: preserve source/update/retrieval timestamps, refresh before decisions when permitted, use an explicit maximum-age gate, and withhold stale/missing ranks. The 72-hour fixture policy is experimental, not a validated production cadence. Public display, exports and long-term private retention need separate confirmation.
Ask FantasyPros to confirm: personal hosted analyzer eligibility under current non-compete language; authenticated private versus public display/export; exact ROS endpoint coverage; current numeric quotas; permitted cache/retention and deletion rules; and whether MCP-derived data may feed private scheduled imports. These are unresolved questions, not requests sent on the user’s behalf.
